# 📝 TodoList Dashboard

A simple **Task Management / Todo Dashboard** built using **Node.js, Express.js, and EJS**.
This application allows users to **add, view, update, and delete tasks** while tracking their status.

---

## 🚀 Features

* Dashboard home page
* Task statistics cards
* Add new tasks
* Update existing tasks
* Delete tasks
* Task table with details
* Status tracking

---

## 📊 Status Flow

```
Pending → In Progress → Completed
```

---

## 🛠 Technologies Used

* Node.js
* Express.js
* EJS (Embedded JavaScript Templates)
* HTML
* CSS

---

## ⚙ Installation

1. Install dependencies

```
npm install
```

2. Run the server

```
node app.js
```

3. Open browser

```
http://localhost:8088
```

---

## 📋 Dashboard Module

The dashboard acts as the **home page of the application**.

### UI Contains

* Header section
* Task statistics cards
* Add task button
* Task table

### Dashboard Cards

* Total Tasks
* Pending Tasks
* In Progress Tasks
* Completed Tasks

### Output

Users can instantly view the **summary of all tasks and their current status**.

---

## 🔄 CRUD Operations

| Operation | Description             |
| --------- | ----------------------- |
| Create    | Add a new task          |
| Read      | View tasks in dashboard |
| Update    | Edit task details       |
| Delete    | Remove tasks            |

## 🌟 Overview

This project is a **modern admin dashboard** built using **Node.js** and **Express.js**, where static HTML pages are converted into dynamic **EJS templates**.

🔹 Clean UI
🔹 Reusable components
🔹 Multiple UI pages
🔹 Beginner-friendly project

---

## 🧰 Tech Stack

| Technology   | Usage             |
| ------------ | ----------------- |
| 🟢 Node.js   | Backend runtime   |
| ⚡ Express.js | Server framework  |
| 🎨 EJS       | Templating engine |
| 💻 HTML/CSS  | UI Design         |

---

## 🚀 Getting Started

### 📥 Installation

```id="3a4h82"
git clone https://github.com/your-username/admin-panel.git
cd admin-panel
npm install
```

### ▶️ Run Project

```id="bq0d8l"
node app.js
```

🌐 Open in browser:
👉 (http://localhost:8008/)

# 🎬 Netflix Clone (Movie Management System)

A full-stack movie management web app built using **Node.js, Express, MongoDB, and EJS**.
This project allows users to add, view, edit, and delete movies with a modern UI.

---

## 🚀 Features

* ➕ Add new movies with poster upload
* 🎞️ View all movies (table & card view)
* 🔍 View single movie details page
* ✏️ Edit movie information
* ❌ Delete movies
* 📁 Image upload using Multer
* 🎨 Clean modern UI (Netflix-inspired)

---

## 🛠️ Tech Stack

* Node.js
* Express.js
* MongoDB (Mongoose)
* EJS (Template Engine)
* Multer (File Upload)
* CSS (Custom Styling)
